# KaneMode 4.30.0

## Streaming : les jeux de votre PC dans la bibliothèque de la console

- **Sur la console** (ROG Ally, PC portable) : **Paramètres → Streaming → Jeux de vos PC dans la bibliothèque** liste les jeux de chaque PC. Ceux que vous cochez rejoignent la bibliothèque avec leur jaquette et un **logo streaming** dans le coin. **Jouer** lance directement le jeu sur son PC, sans passer par l’accueil du streaming, et revient à KaneMode à la fin de la partie.
- **Sur le PC qui diffuse** : **Paramètres → Streaming → Proposer mes jeux aux consoles** propose à Sunshine tous les jeux installés de KaneMode (émulation comprise), avec leur jaquette. La liste suit la bibliothèque, jamais pendant un streaming. La première fois, Windows demande les droits d’administrateur.
  - Le jeu démarre par le KaneMode du PC, avec ses réglages habituels (manette, préréglages, mods). Quitter le jeu sur le PC termine le streaming. Quitter la session depuis la console ferme le jeu sur le PC.
- Les jaquettes des jeux de vos PC sont téléchargées par le streaming dès qu’il connaît le PC.

## Installation

Installez **KaneMode-Setup-4.30.0.exe**, ou ouvrez **Paramètres → Système → Mises à jour** dans une version existante, sur le PC et sur la console. Le certificat de signature habituel est conservé.
