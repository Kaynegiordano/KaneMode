# KaneMode 4.0.6

Cette version propose de quitter Steam quand on active le mode souris, parce que Steam garde les manettes Xbox tant qu'il tourne.

## Mode souris et Steam

- Le journal d'une ROG Ally montrait que le curseur se déplaçait hors de KaneMode quand Steam était fermé, et plus du tout une fois Steam lancé : Steam Input prend les manettes Xbox et leurs sticks arrivent à zéro pour les autres programmes. Steam fermé, le mode souris refonctionne dans les autres fenêtres.
- À l'activation du mode souris dans KaneMode, si Steam tourne sans jeu lancé, une question s'affiche : **Quitter Steam**, **Garder Steam** ou **Ne plus demander**. Elle n'apparaît qu'une fois par activation, jamais pendant un jeu Steam, et seulement si KaneMode est devant.
- Steam est fermé par sa commande officielle (`steam.exe -shutdown`). Il se relance tout seul au prochain jeu Steam lancé depuis KaneMode ; le démarrage de Steam en arrière-plan avec KaneMode (Paramètres → Bibliothèque → Lancement des jeux) reste inchangé. Aucun réglage de Steam n'est modifié.
- **Paramètres → Manette** : « Proposer de quitter Steam avec le mode souris » permet de réactiver ou de couper la question.

## Installation

Installez **KaneMode-Setup-4.0.6.exe**, ou ouvrez **Paramètres → Système → Mises à jour** dans une version existante. Le certificat de signature habituel est conservé.
