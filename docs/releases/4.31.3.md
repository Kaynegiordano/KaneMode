# KaneMode 4.31.3

## Streaming : corrections après les premières parties

- Après une partie lancée depuis la console, le PC croyait le streaming toujours en cours quand on quittait le jeu (et non la connexion) : la liste des jeux proposés à Sunshine n’était plus jamais mise à jour. C’est corrigé.
- Le petit lanceur des jeux reste le même fichier d’une version à l’autre : Windows Defender ne le réanalyse plus après chaque mise à jour, ce qui retardait d’environ 15 secondes le premier lancement depuis la console.

## Installation

Ouvrez **Paramètres → Système → Mises à jour** sur le PC qui diffuse, ou installez **KaneMode-Setup-4.31.3.exe**. Le certificat de signature habituel est conservé.
