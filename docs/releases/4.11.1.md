# KaneMode 4.11.1

## Complément PC hôte intégré

- Le complément qui change l'échelle du PC hôte pendant le streaming est maintenant **dans KaneMode**. Sur un PC qui diffuse avec Sunshine, **Paramètres → Streaming → Complément PC hôte** indique s'il est installé et propose **Installer**, **Mettre à jour** ou **Retirer**. Windows demande les droits d'administrateur, puis Sunshine redémarre.
- KaneMode signale quand une appli ajoutée dans Sunshine n'a pas encore ses variantes, ou quand une nouvelle version du complément est disponible.
- Le fichier **KaneMode-Hote-Echelle** reste sur la page des versions, pour un PC hôte sans KaneMode.

## Installation

Installez **KaneMode-Setup-4.11.1.exe**, ou ouvrez **Paramètres → Système → Mises à jour** dans une version existante. Le certificat de signature habituel est conservé.
