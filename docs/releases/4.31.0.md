# KaneMode 4.31.0

## Installation : « Ce PC sert à… »

- L’installateur demande d’abord à quoi sert le PC, et règle le reste tout seul :
  - **Jouer** (console, PC portable) : mode Xbox et mode développeur cochés, comme avant ;
  - **Streamer** (le PC qui diffuse) : Sunshine en manette automatique, jeux de KaneMode proposés aux consoles (sans autre demande d’administrateur), complément d’échelle installé ; mode Xbox décoché ;
  - **Les deux** : tout cela à la fois.
- Le choix est pré-coché d’après la machine (une carte graphique dédiée propose « Les deux », sinon « Jouer ») et reste modifiable, comme chaque option. Sans Sunshine, l’installateur le dit, sans rien télécharger.
- Les options déjà faites sur le PC (mode Xbox, mode développeur) s’affichent cochées et lisibles.

## Installation

Lancez **KaneMode-Setup-4.31.0.exe** (droits administrateur demandés une fois). Les mises à jour depuis **Paramètres → Système → Mises à jour** ne reposent pas la question : tout reste réglable dans Paramètres → Streaming.
