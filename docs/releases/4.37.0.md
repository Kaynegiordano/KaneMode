# KaneMode 4.37.0

## Quitter un jeu

- **Select + Start** (ou **Échap**) se maintiennent maintenant **5 secondes** pour revenir à KaneMode en gardant la partie, et **8 secondes** pour quitter complètement. Un appui un peu long sur Moins + Plus, qui ouvre le menu de certains portages PC comme Zelda Ocarina of Time, ne ferme plus le jeu par erreur.
- Les vibrations sont les mêmes : une petite quand KaneMode est prêt à fermer le jeu au relâchement, une longue pour la sortie complète.

## Installation

Ouvrez **Paramètres → Système → Mises à jour** sur la console, ou installez **KaneMode-Setup-4.37.0.exe**. Le certificat de signature habituel est conservé.
