# KaneMode 4.5.0

Cette version revient à la base de la 4.1.0 : **GeForce NOW (OpenNOW) est retiré**, et le mode souris à la manette est un peu plus léger.

## GeForce NOW retiré

- L'entrée « GeForce NOW » du menu, le client OpenNOW et tout ce qui s'y rattache disparaissent. Les versions 4.2.0 et 4.2.1 sont annulées.
- Le paquet redevient plus léger : environ 136 Mo au lieu de 202 Mo.
- Le raccourci web « GeForce NOW » de la page d'ajout d'un jeu (ouvre play.geforcenow.com dans le navigateur) reste disponible.

## Mode souris plus léger

- La lecture de la manette par Raw Input, qui fait fonctionner le mode souris devant toutes les fenêtres de l'expérience Xbox, n'est active que pendant le mode souris. Avant, elle tournait en permanence : une manette envoie des centaines de rapports par seconde, qui passaient par l'interface même sans mode souris.
- Les manettes qui ne sont pas des manettes Xbox ou DualShock sont ignorées, et la lecture n'alloue plus de mémoire à chaque rapport.

## Inchangé

Tout le reste de la 4.1.0 : mode souris (A clic, Y clic droit, B retour, X + stick défilement…), diagnostic du curseur, suppression de captures, pilotes graphiques, Dolby Atmos, bibliothèques de comptes, etc.

## Installation

Installez **KaneMode-Setup-4.5.0.exe**, ou ouvrez **Paramètres → Système → Mises à jour** dans une version existante. Le certificat de signature habituel est conservé.
