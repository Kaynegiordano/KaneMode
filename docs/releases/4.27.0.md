# KaneMode 4.27.0

## Mises à jour de KaneMode

- La mise à jour ne s’arrête plus sur une erreur d’empreinte SHA-256 quand GitHub répond mal : le 9 novembre, l’adresse de téléchargement de GitHub renvoyait une erreur 504, lue à tort comme la liste des empreintes. KaneMode réessaie maintenant, puis passe par l’API de GitHub, qui sert les mêmes fichiers. L’empreinte du paquet est toujours vérifiée.

## Émulation : Preset IA plus fin (Switch 2)

- **Profil de la machine qui lance le jeu** : carte très haut de gamme (GeForce RTX 4070 Ti à 5090, Radeon RX 7900 / 9070), autre carte dédiée ou console portable, avec le processeur et la mémoire affichés dans le résumé du preset.
- Sur une carte très haut de gamme, les jeux limités par le processeur sont calculés en plus grand pour une image plus fine (Zelda Ocarina of Time en 2x, jeux inconnus en 1,5x).
- **Shaders compilés au chargement** : plus de saccades la première fois qu’un effet apparaît (le premier lancement d’un jeu est plus long ; l’émulateur propose de passer).
- **Donkey Kong Bananza** n’est plus bloqué à 30 i/s quand le mod intégré Dynamic FPS est actif : images libres, vitesse juste de 20 à 60 i/s.
- Le Preset IA se choisit dans Réglages → Préréglage (D’origine reste le choix par défaut).

## Installation

Installez **KaneMode-Setup-4.27.0.exe**, ou ouvrez **Paramètres → Système → Mises à jour** dans une version existante. Le certificat de signature habituel est conservé.
