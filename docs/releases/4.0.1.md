# KaneMode 4.0.1

Cette version corrige le mode souris qui coupait la navigation à la manette dans KaneMode. Le curseur devient un contrôle supplémentaire, sans désactiver les boutons ni le stick de navigation.

## Souris et manette ensemble

- Dans KaneMode : **stick gauche et boutons pour naviguer, stick droit pour déplacer le curseur**. Les états natifs de manette continuent d’être transmis à l’interface pendant le mode souris.
- Les boutons conservent leurs fonctions habituelles ; ils ne génèrent pas en plus un clic ou un défilement Windows dans KaneMode, afin d’éviter une double validation ou une double action.
- Un appui court sur **Start / Options** conserve son action de menu ou d’accès rapide selon votre réglage. Un maintien bascule le mode souris, y compris pour les manettes vues uniquement par WebView2, sans second basculement après celui du lecteur natif.
- Dans les autres fenêtres, les commandes souris restent disponibles : sticks, clics, glissé, molette et précédent/suivant. Le mode reste actif entre fenêtres tant que KaneMode reste ouvert.
- Un bouton encore tenu au passage vers une autre fenêtre attend son relâchement avant de devenir un clic. La navigation de KaneMode reste suspendue derrière un jeu ou le streaming.

## Vérifications

Les tests natifs vérifient les données de manette conservées, le curseur indépendant, l’absence de double clic et les boutons tenus lors d’un changement de fenêtre. Les essais Chromium couvrent les validations uniques avec les deux sources de manette, la croix directionnelle, Start court et long, les basculements et le streaming en arrière-plan.

47 tests Node et 120 mises en page Chromium passent. Les entrées de manette et l’injection de souris sont simulées dans les bancs d’essai ; le fonctionnement physique sur votre console reste à confirmer. Les restrictions Windows pour les fenêtres administrateur, les écrans sécurisés et les jeux capturant la souris restent applicables.

## Installation

Installez **KaneMode-Setup-4.0.1.exe**, ou ouvrez **Paramètres → Système → Mises à jour** dans une version existante. Le certificat de signature habituel est conservé.
