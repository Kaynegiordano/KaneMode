# KaneMode 4.2.0

Cette version intègre **GeForce NOW** à KaneMode, grâce au client libre [OpenNOW](https://github.com/OpenCloudGaming/OpenNOW).

## GeForce NOW

- Nouvelle entrée **GeForce NOW** dans le menu de KaneMode.
- Il s'ouvre en plein écran, en affichage console pour la manette, aux couleurs de KaneMode : votre couleur d'accent, vos coins, sélection en blanc.
- **B** sur son accueil ramène à KaneMode, qui reprend la main et les manettes.
- Il faut votre propre compte GeForce NOW. La connexion se fait dans GeForce NOW lui-même : KaneMode ne lit ni ne garde rien de votre compte.
- Son interface est encore en grande partie en anglais.

OpenNOW est un projet communautaire, encore jeune, ni affilié ni approuvé par NVIDIA. GeForce NOW est une marque de NVIDIA. Ses correctifs seront repris dans les prochaines versions de KaneMode.

## Vérifications

Client compilé et lancé depuis KaneMode, retour par B vérifié, application compilée. La connexion et une partie complète sont à confirmer sur la console.

## Installation

Installez **KaneMode-Setup-4.2.0.exe**, ou ouvrez **Paramètres → Système → Mises à jour** dans une version existante. Le certificat de signature habituel est conservé. Le paquet grossit d'environ 170 Mo (GeForce NOW).
