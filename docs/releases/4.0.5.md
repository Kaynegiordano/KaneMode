# KaneMode 4.0.5

Cette version rend visible le curseur du mode souris devant toutes les applications de l'expérience Xbox, et pas seulement devant KaneMode.

## Curseur du mode souris en expérience Xbox

- Le journal d'une ROG Ally montrait que le curseur se déplaçait bien dans les autres fenêtres (Epic Games Launcher, vue des tâches : mouvements acceptés par Windows, aucun refus), mais la flèche de KaneMode se masquait dès qu'une application annonçait son propre curseur, alors que l'expérience Xbox ne dessine aucun pointeur.
- En expérience Xbox, la flèche reste désormais affichée partout tant que le mode souris est actif. Sur le bureau Windows classique, rien ne change : elle n'apparaît que si Windows cache son curseur.
- Si Windows dessine malgré tout son curseur dans une application, deux flèches presque superposées peuvent apparaître.

## Diagnostic

Le journal indique quand la flèche est affichée ou masquée et pourquoi (« Curseur supplémentaire : … »), vingt lignes au plus par activation. Les lignes « Sources » de la 4.0.4 restent présentes.

## Installation

Installez **KaneMode-Setup-4.0.5.exe**, ou ouvrez **Paramètres → Système → Mises à jour** dans une version existante. Le certificat de signature habituel est conservé.
