# KaneMode 4.36.0

## Journal dans les Paramètres

- **Paramètres → Système → Journal** : les dernières erreurs de KaneMode et de la dernière session de streaming, avec leur heure. Un message répété n’apparaît qu’une fois, avec son nombre.
- **Copier le journal** met la fin des journaux dans le presse-papiers, à coller dans un message. A sur une erreur la copie seule.
- Le moteur de streaming écrit maintenant son journal quand il est lancé par KaneMode (il n’en écrivait aucun).

## Corrections

- KaneMode ne s’arrête plus quand l’outil des réglages graphiques se ferme pendant une commande (plantage relevé dans le journal d’une console).
- Même protection pour les réglages du système (énergie, écran, son).

## Vérifications

- Le test d’interface tourne de nouveau, dans Microsoft Edge sans fenêtre, et une analyse automatique du code est lancée avant chaque version.

## Installation

Ouvrez **Paramètres → Système → Mises à jour** sur la console, ou installez **KaneMode-Setup-4.36.0.exe**. Le certificat de signature habituel est conservé.
