# KaneMode 4.1.0

Cette version complète le mode souris maintenant qu'il fonctionne devant toutes les fenêtres de l'expérience Xbox, et retire la question sur Steam.

## Nouvelle disposition des boutons

Dans les fenêtres autres que KaneMode :

| Commande Xbox / PS4 | Action |
| --- | --- |
| Stick gauche ou droit | Déplacer le curseur |
| A / Croix | Clic gauche, maintenir pour glisser |
| Y / Triangle | Clic droit |
| B / Cercle | Retour |
| X / Carré maintenu + stick | Défilement vertical et horizontal, le curseur reste en place |
| Croix directionnelle | Défilement par crans |
| LB / L1 | Clic du milieu |
| RB / R1 | Avancer |

Le clic droit passe de B à Y pour que B serve de retour, et le clic du milieu de X à LB. Dans KaneMode, les boutons gardent leurs fonctions de navigation. Le rappel affiché à l'activation, Paramètres → Manette, le widget Game Bar et le guide `docs/mouse-mode.md` suivent cette disposition.

## Retiré

- La question « Quitter Steam ? » à l'activation du mode souris, son réglage et ses routes : Steam n'était pas la cause du problème, la lecture de la manette par Raw Input (4.0.7) l'a résolu.

## Vérifications

Banc d'essai de la souris mis à jour (disposition des boutons, défilement au stick, curseur immobile pendant le défilement), 49 tests Node et application compilée sans avertissement. La disposition est à confirmer à la manette sur la console.

## Installation

Installez **KaneMode-Setup-4.1.0.exe**, ou ouvrez **Paramètres → Système → Mises à jour** dans une version existante. Le certificat de signature habituel est conservé.
