# KaneMode 4.35.1

## HDR automatique : exclure l’émulation

- Nouvelle option **Exclure l’émulation** (Paramètres → Son et image → HDR automatique), activée par défaut : les jeux émulés, les portages PC et les émulateurs (RetroArch, Dolphin, Eden…) ne passent jamais l’écran en HDR, même lancés depuis Steam ou ouverts hors de KaneMode.
- Un jeu réglé sur « Toujours » dans **HDR du jeu** passe avant l’exclusion.
- Option coupée : les jeux émulés suivent le réglage « Jeux lancés depuis KaneMode », comme les autres jeux.

## Installation

Ouvrez **Paramètres → Système → Mises à jour** sur la console, ou installez **KaneMode-Setup-4.35.1.exe**. Le certificat de signature habituel est conservé.
