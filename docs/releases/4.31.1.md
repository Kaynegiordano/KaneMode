# KaneMode 4.31.1

## Streaming : les jeux du PC arrivent enfin dans Sunshine

- Avec « Proposer mes jeux aux consoles » activé, la liste des jeux n’était jamais écrite : KaneMode voulait d’abord poser une copie de sécurité dans le dossier de Sunshine, où il n’a que le droit de modifier la liste elle-même (« EPERM » toutes les minutes dans le journal). La copie est maintenant gardée chez KaneMode, et la liste est écrite.
- Après la mise à jour du PC qui diffuse, ses jeux apparaissent dans Sunshine en une minute. Sur la console, ouvrez une fois le streaming de ce PC, puis cochez les jeux dans **Paramètres → Streaming → Jeux de vos PC dans la bibliothèque**.

## Installation

Ouvrez **Paramètres → Système → Mises à jour** sur le PC qui diffuse (et sur la console si besoin), ou installez **KaneMode-Setup-4.31.1.exe**. Le certificat de signature habituel est conservé.
