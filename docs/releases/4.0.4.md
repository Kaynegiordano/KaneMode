# KaneMode 4.0.4

Cette version ajoute un diagnostic détaillé des manettes pour comprendre pourquoi le mode souris ne répond pas hors de KaneMode sur certaines consoles (ROG Ally en expérience Xbox). Elle ne change pas le comportement du mode souris.

## Diagnostic dans `kanemode.log`

- À l'ouverture d'une manette HID : taille du rapport et plage de chaque axe, puis les deux premiers rapports reçus en hexadécimal.
- Pendant le mode souris : toutes les 5 secondes (40 lignes au plus par activation), une ligne « Sources » indique la fenêtre au premier plan et ce que reçoit chaque source (XInput, HID, relais WebView2) : paquets, axes décodés et dernier rapport brut.

Pour aider au diagnostic : activez le mode souris (Start maintenu 1 s), passez dans une autre fenêtre, bougez les sticks, revenez dans KaneMode, puis envoyez `%LOCALAPPDATA%\KaneMode\logs\kanemode.log`.

## Installation

Installez **KaneMode-Setup-4.0.4.exe**, ou ouvrez **Paramètres → Système → Mises à jour** dans une version existante. Le certificat de signature habituel est conservé.
