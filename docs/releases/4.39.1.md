# KaneMode 4.39.1

## Streaming

- **LB + RB + Select + Y** doit maintenant être maintenu 5 secondes pour couper la session : plus de coupure par accident. Un message s’affiche pendant le maintien ; relâchez avant la fin et le jeu continue.
- L’écran de lancement d’un jeu streamé rappelle comment quitter et comment ouvrir le menu du streaming.

## Corrections

- Images par seconde : la dernière minute d’une partie compte dans la valeur la plus basse.
- La fréquence d’écran réglée pour un jeu ne s’applique plus à un jeu streamé.

## Installation

Ouvrez **Paramètres → Système → Mises à jour** sur la console, ou installez **KaneMode-Setup-4.39.1.exe**. Le certificat de signature habituel est conservé.
