# KaneMode 4.19.0

## Switch 2

- **Jeux au format .nup** : les jeux en .nup, le format de Lichii (comme « The Legend of Zelda Ocarina of Time [….nup] »), apparaissent maintenant dans la console Switch 2 et se lancent directement.
- **Réglages selon la machine** (Switch et Switch 2) :
  - **sur la ROG Ally** et les autres consoles portables à puce graphique intégrée : mode portable, précision graphique allégée et agrandissement FSR jusqu'à l'écran ;
  - **sur un PC avec une carte graphique dédiée** : mode TV et résolution choisie d'après l'écran.
- « Qualité de l'image : d'origine » est aussi proposé pour Eden et Lichii, dans les réglages du jeu ou de la console.

## Installation

Installez **KaneMode-Setup-4.19.0.exe**, ou ouvrez **Paramètres → Système → Mises à jour** dans une version existante. Le certificat de signature habituel est conservé.
