# KaneMode 4.0.7

Cette version tente de rendre le mode souris utilisable devant toutes les fenêtres de l'expérience Xbox, en lisant la manette par Raw Input.

## Pourquoi

Le journal d'une ROG Ally montre que, dans l'expérience Xbox, Windows ne donne la manette qu'à la fenêtre qui a le focus : hors de KaneMode, XInput renvoie des sticks à zéro et la lecture directe du périphérique ne reçoit presque rien. Hors expérience Xbox (bureau Windows), le mode souris fonctionne dans les autres fenêtres. Fermer Steam ne change pas cela.

## Ce qui change

- Une fenêtre cachée de KaneMode reçoit les rapports des manettes par **Raw Input** : c'est le système qui les lui livre, qu'une autre fenêtre ait le focus ou non. Ils sont décodés comme ceux de la lecture directe et alimentent le mode souris.
- Les lignes « Sources » de `kanemode.log` comptent désormais les rapports reçus par ce canal (`raw=`).

Cette version est un essai : si l'expérience Xbox filtre aussi Raw Input, le journal le montrera (`raw=` qui n'augmente pas quand on bouge le stick devant une autre fenêtre) et la piste suivante sera GameInput.

## Pour aider au diagnostic

Activez le mode souris (Start maintenu 1 s), passez dans une autre fenêtre (Epic, Explorateur, navigateur), bougez le stick droit une dizaine de secondes, puis envoyez `%LOCALAPPDATA%\KaneMode\logs\kanemode.log`.

## Installation

Installez **KaneMode-Setup-4.0.7.exe**, ou ouvrez **Paramètres → Système → Mises à jour** dans une version existante. Le certificat de signature habituel est conservé.
