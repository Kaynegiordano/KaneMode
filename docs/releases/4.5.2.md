# KaneMode 4.5.2

Version de maintenance, alignée sur **Kane OS 4.5.2** : le code de l'application n'a pas changé depuis la 4.5.0.

## Avec Kane OS

- Kane OS (le lanceur de bureau, dépôt privé) a maintenant un onglet et une carte KaneMode : version installée, **Lancer** (KaneMode s'ouvre au premier plan), **Fermer**.
- Kane OS suit les versions de KaneMode publiées ici, canal **Stable** ou **Bêta**. Avant toute installation, le paquet est téléchargé depuis GitHub et son SHA-256 est contrôlé avec `SHA256SUMS` ; sans empreinte, la mise à jour est refusée.

## Inchangé

Tout le reste de la 4.5.0 : mode souris partout dans l'expérience Xbox, bibliothèque multi-boutiques, streaming local, émulation, pilotes graphiques, Dolby Atmos, etc.

## Installation

Installez **KaneMode-Setup-4.5.2.exe**, ou ouvrez **Paramètres → Système → Mises à jour** dans une version existante. Le certificat de signature habituel est conservé.
