# KaneMode 4.33.0

## Nouveau logo

- KaneMode a son propre logo : un K dont les branches s’ouvrent sur les quatre boutons d’une manette, toujours dans le dégradé bleu → violet de KaneMode. Il remplace l’ancien K, partagé avec KaneOS.
- Nouveau partout : icône de l’app, du menu Démarrer et de la barre des tâches, installateur, interface (accueil, démarrage, au revoir) et widget de la Game Bar. Dans l’interface, le logo suit toujours votre couleur d’accent.

## Installation

Ouvrez **Paramètres → Système → Mises à jour**, ou installez **KaneMode-Setup-4.33.0.exe**. Le certificat de signature habituel est conservé. Windows peut garder l’ancienne icône en mémoire quelques minutes.
