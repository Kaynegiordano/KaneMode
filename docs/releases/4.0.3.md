# KaneMode 4.0.3

Cette version est une passe de robustesse : trois erreurs isolées ne peuvent plus arrêter l'hôte ou KaneMode.

## Corrections

- **Hôte** : un fichier supprimé ou verrouillé pendant son envoi (par exemple une capture effacée alors que sa vignette se charge) ne fait plus s'arrêter l'hôte. Une plage de lecture vidéo invalide reçoit une réponse 416 ; les plages `bytes=-N` sont prises en charge et une fin trop grande est ramenée à la taille du fichier.
- **Manettes** : une erreur imprévue dans la boucle de lecture, qui fait aussi vivre le mode souris, est notée dans le journal (au plus une ligne toutes les 10 s) et la lecture continue au lieu de fermer KaneMode.
- **Manettes HID** : un rapport inattendu referme seulement la manette concernée, qui est rouverte à la recherche suivante, avec une ligne dans le journal.
- **Journal** : une exception sur un autre thread est maintenant écrite dans `kanemode.log` avant l'arrêt de l'application, pour en retrouver la cause.

## Vérifications

49 tests Node et tests natifs (souris, DualShock, protection contre le verrouillage, premier plan) réussis, application compilée sans avertissement. Les plages vidéo invalides, valides et la suppression d'un fichier en cours d'envoi ont été essayées sur un hôte local. Les mises en page Chromium n'ont pas été relancées pour cette version, qui ne touche pas à l'interface.

## Installation

Installez **KaneMode-Setup-4.0.3.exe**, ou ouvrez **Paramètres → Système → Mises à jour** dans une version existante. Le certificat de signature habituel est conservé.
