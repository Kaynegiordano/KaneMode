# KaneMode 4.28.0

## Émulation : portages PC dans les consoles

- Un **raccourci Windows** vers un jeu PC, posé dans le dossier d’une console (par exemple « Nintendo Switch 2 »), devient un jeu de cette console : il est lancé directement, sans émulateur. C’est fait pour les portages et recompilations (Zelda Ocarina of Time avec NX2navi, Sonic 3 A.I.R.…).
- Le jeu garde sa jaquette, son fond et ses infos. Select + Start ou Échap ramènent à KaneMode comme pour les autres jeux.
- Ni mods ni réglages d’émulateur pour ces jeux : ils se règlent dans le jeu lui-même.

## Installation

Installez **KaneMode-Setup-4.28.0.exe**, ou ouvrez **Paramètres → Système → Mises à jour** dans une version existante. Le certificat de signature habituel est conservé.
