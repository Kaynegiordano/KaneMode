# KaneMode 4.31.2

## Streaming : les jeux du PC démarrent depuis la console

- Lancer un jeu du PC depuis la console affichait « l’hôte a renvoyé une erreur : Failed to start the specified application ». Sunshine ne parvenait pas à démarrer KaneMode (accès refusé par Windows à l’app installée, lancée depuis Sunshine). Il passe maintenant par un petit lanceur ordinaire que KaneMode installe dans son dossier : le jeu démarre par le KaneMode du PC, et le streaming s’arrête quand vous le quittez.
- Après la mise à jour du PC qui diffuse, ses jeux sont republiés dans Sunshine en une minute (Sunshine redémarre une fois). Rien à refaire sur la console.

## Installation

Ouvrez **Paramètres → Système → Mises à jour** sur le PC qui diffuse, ou installez **KaneMode-Setup-4.31.2.exe**. Le certificat de signature habituel est conservé.
