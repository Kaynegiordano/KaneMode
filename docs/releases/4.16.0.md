# KaneMode 4.16.0

## Émulation : pensée pour la ROG Ally

- **Plus de bandeau qui mange l'écran** : l'accueil Émulation n'a plus d'en-tête ni de grande bannière. Les jaquettes sont plus grandes, avec leur nom lisible dessous, et l'image du jeu choisi passe en fond. « Ajouter des jeux » et « Gérer » sont dans une dernière rangée, « Options ».
- **Dans une console** : une seule ligne en haut (la console, LB / RB pour en changer, les filtres, les réglages), puis la grille des jeux.
- **La page du jeu** : A sur une jaquette ouvre le jeu en grand, avec sa jaquette, son logo, sa description et quatre onglets (LB / RB) :
  - **Jouer** : jouer, recommencer du début sans la reprise automatique, favori ;
  - **Réglages** : les réglages de ce jeu (filtre, format, qualité, écran large, émulateur) ;
  - **Visuels** : changer la jaquette, le logo, le fond ou la bannière ;
  - **Infos** : développeur, éditeur, sortie, émulateur, fichier.
- A de nouveau lance le jeu. Y lance un jeu tout de suite, sans passer par sa page.

## Mega Drive et Mega-CD

- **Sonic & Knuckles** ne reste plus sur un écran noir : son archive contient aussi la puce « Lock-on », que RetroArch prenait pour le jeu. KaneMode regarde maintenant dans les archives et donne le bon fichier.
- **Sonic CD** et les autres jeux Mega-CD rangés dans le dossier Mega Drive vont dans la console Mega-CD. Il leur faut le BIOS Mega-CD de leur région, que KaneMode demande avant de décompresser le jeu. Le BIOS est reconnu quel que soit son nom.

## Installation

Installez **KaneMode-Setup-4.16.0.exe**, ou ouvrez **Paramètres → Système → Mises à jour** dans une version existante. Le certificat de signature habituel est conservé.
