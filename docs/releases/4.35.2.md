# KaneMode 4.35.2

## Revue de code : robustesse

- **Réglages protégés** : les fichiers de réglages, d’état et de bibliothèque sont écrits d’un seul coup, avec une copie de secours. Une console qui s’éteint en pleine écriture (batterie vide) ne peut plus repartir de réglages vides.
- **Streaming** : relancer un streaming dans les 10 secondes qui suivent la fin d’une session ne risque plus de le voir arrêté par KaneMode.
- L’hôte ne s’arrête plus sur une adresse mal formée ni sur une erreur oubliée dans une tâche de fond ; la cause est notée dans le journal.
- Les jaquettes, l’aperçu d’image et la vidéo de démarrage ne sont plus servis à la page d’un autre site ouverte sur ce PC.
- Performance du jeu : une limite d’images changée pendant que le jeu tourne s’applique tout de suite ; deux jeux à mode propre lancés à la suite rendent bien le mode d’origine.
- Petites fuites de ressources corrigées dans l’app (suivi du moteur de streaming) et restes de code retirés.

## Installation

Ouvrez **Paramètres → Système → Mises à jour** sur la console, ou installez **KaneMode-Setup-4.35.2.exe**. Le certificat de signature habituel est conservé.
