# KaneMode 4.20.0

## Émulation : quitter un jeu complètement

- **Select + Start (ou Échap) maintenus 1 seconde** : une petite vibration, et le jeu se ferme quand vous relâchez. La partie est gardée : au prochain lancement, vous reprenez là où vous étiez.
- **Maintenus 3 secondes** : une vibration plus longue, et le jeu se ferme complètement. Au prochain lancement, il repart du début. Les sauvegardes faites dans le jeu restent.
- Le rappel est affiché sur l'écran de lancement.

## Installation

Installez **KaneMode-Setup-4.20.0.exe**, ou ouvrez **Paramètres → Système → Mises à jour** dans une version existante. Le certificat de signature habituel est conservé.
