# KaneMode 4.2.1

Cette version corrige GeForce NOW qui restait bloqué sur « Loading the live catalog… » sans pouvoir se connecter.

## GeForce NOW

- Le moteur d'OpenNOW, qui gère le catalogue, la connexion et la plupart des réglages, refusait de démarrer quand son dossier de captures (sous Images) était introuvable, par exemple un dossier Images redirigé vers un disque absent. Il démarre maintenant dans tous les cas : seule la médiathèque est alors indisponible.
- Si le moteur ne démarre pas pour une autre raison, l'écran Magasin affiche « Starting the OpenNOW core… » et la dernière erreur du moteur, au lieu de « Loading… » sans fin.

## À savoir

La cause exacte du blocage constaté sur la console n'est pas confirmée : le dossier Images est la cause trouvée dans les journaux du PC de développement. Si le blocage persiste, le message affiché sous « Starting the OpenNOW core… » ou le fichier `qt-native.log` (dans `%APPDATA%\OpenNOW\diagnostics`, ou dans le dossier du paquet KaneMode) permettront de la trouver.

## Installation

Installez **KaneMode-Setup-4.2.1.exe**, ou ouvrez **Paramètres → Système → Mises à jour** dans une version existante. Le certificat de signature habituel est conservé.
