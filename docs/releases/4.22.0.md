# KaneMode 4.22.0

## Émulation : jeux Switch 2 lancés à jour

- Un jeu en dossier qui a une mise à jour (`updates/…`) démarre maintenant dans sa dernière version, et non plus en version 1.0.
- Pokopia démarre : son dossier de base n’a pas les données du jeu, seule la mise à jour les contient.
- Si la mise à jour ne contient que les fichiers modifiés, le jeu de base reste lancé.
- Les favoris, jaquettes et réglages du jeu sont gardés.
- Le nom d’un jeu en dossier n’est plus coupé (« Pokopia » au lieu de « Pokopia (v2.0 »).

## Installation

Installez **KaneMode-Setup-4.22.0.exe**, ou ouvrez **Paramètres → Système → Mises à jour** dans une version existante. Le certificat de signature habituel est conservé.
