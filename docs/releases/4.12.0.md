# KaneMode 4.12.0

## Compteur de données du streaming

- **Pendant le streaming**, le menu du jeu (Start + Select) affiche les données déjà consommées à côté du nom du PC, et les statistiques de performance ajoutent une ligne **DATA**.
- **À la fin de la session**, le bilan montre une nouvelle carte **Données** : ce que la session a consommé, et le **total du mois**.
- Le calcul suit ce qui passe vraiment par le réseau : vidéo, correction d'erreurs et son, en-têtes compris.

## Installation

Installez **KaneMode-Setup-4.12.0.exe**, ou ouvrez **Paramètres → Système → Mises à jour** dans une version existante. Le certificat de signature habituel est conservé.
