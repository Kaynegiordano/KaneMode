# KaneMode 4.0.2

Cette version corrige deux défauts dans la transmission des mouvements de manette au mode souris : le choix de la source d’entrée et le décodage des axes HID.

## Corrections du mode souris

- Une manette native détectée mais sans mouvement ne bloque plus les axes reçus par WebView2. La dernière commande réelle choisit la source ; les remises au neutre, déconnexions et copies retardées sont prises en compte.
- Les états WebView2 figés en arrière-plan expirent pour éviter de maintenir un ancien mouvement. Une entrée fraîche permet de reprendre le relais.
- Le lecteur HID traite désormais tous les axes d’une plage de capacités, les valeurs signées et les identifiants de rapport et de collection. Les rapports séparés conservent les autres axes déjà lus.
- La navigation à la manette reste disponible : **dans KaneMode, stick gauche et boutons pour naviguer, stick droit pour le curseur**. Dans les autres fenêtres, les commandes souris existantes sont conservées.

## Diagnostic intégré

**Paramètres → Manette → Diagnostic du curseur** affiche l’état du mode souris et les compteurs de mouvements acceptés ou refusés par Windows. Les changements d’état et la source utilisée sont inscrits dans le journal de KaneMode pour faciliter le diagnostic sur une console concernée.

## Vérifications et limites

Les tests natifs couvrent les sources inactives, les doublons retardés, l’expiration du relais et la conversion des valeurs HID en mouvements. Les 49 tests Node passent et vérifient notamment la fraîcheur des états WebView2 ; les essais Chromium couvrent 120 mises en page, la coexistence souris/manette et le diagnostic.

Un essai supplémentaire appelle la véritable fonction Windows d’injection avec un déplacement nul : Windows l’accepte sur le PC de développement, sans déplacer le curseur ni générer de clic. Les entrées de manette des bancs d’essai restent simulées : **le fonctionnement physique sur votre console reste à confirmer**. Une acceptation par Windows ne garantit pas qu’un jeu relâche sa capture du curseur ; les restrictions des fenêtres administrateur et des écrans sécurisés restent applicables.

## Installation

Installez **KaneMode-Setup-4.0.2.exe**, ou ouvrez **Paramètres → Système → Mises à jour** dans KaneMode. Le certificat de signature habituel est conservé.
