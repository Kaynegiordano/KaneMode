# KaneMode 4.21.0

## Émulation : Lichii (Switch 2) mieux réglé

- Lichii reçoit une configuration conseillée, posée une seule fois. Ce que vous changez ensuite dans Lichii reste.
- Elle règle les horloges (CPU normal, GPU boost), le jeu en français (Europe) et la vitesse (100 %, lent 50 %, turbo 200 %). Le CPU passe en « Unsafe » avec 16000 ticks.
- Côté image : Vulkan, Mailbox, netteté RCAS 72 %, SMAA, 60 FPS, mode GPU rapide, shaders et présentation asynchrones.
- Selon la machine :
  - carte NVIDIA RTX : mode TV, DLSS NVIDIA à la place du DLSS des jeux ;
  - ROG Ally : mode portable et FSR.

## Installation

Installez **KaneMode-Setup-4.21.0.exe**, ou ouvrez **Paramètres → Système → Mises à jour** dans une version existante. Le certificat de signature habituel est conservé.
